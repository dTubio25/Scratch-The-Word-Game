# Scratch the Word 🎉

Scratch the Word is a fun and interactive word-guessing game where players scratch the screen to reveal hints and guess the hidden word. Test your vocabulary and enjoy the challenge!

## Features
- **Scratch to Reveal Hints**: Scratch the canvas to uncover hints for the hidden word.
- **Leaderboard**: Track your score and compete with others.
- **Game Over Modal**: Displays when the game ends, with options to try again or quit.
- **Game Completed Modal**: Congratulates the player when all words are completed.
- **Responsive Design**: Works seamlessly on different screen sizes.

## How to Play
1. Enter your name to start the game.
2. Scratch the canvas to reveal hints for the hidden word.
3. Use the on-screen keyboard to guess the word.
4. Earn points for correct guesses and track your score on the leaderboard.
5. Complete all words to win the game!

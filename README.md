🧠 Scratch The Word
Scratch The Word is a fun and interactive word-guessing game where players scratch to reveal hints, guess letters, and try to complete the word before losing all lives. It features sound effects, animated modals, a leaderboard, and admin controls.

🎮 Features
🔠 Interactive virtual keyboard for guessing letters

🪄 Scratchable canvas to reveal word hints

🧍 Player name input

❤️ Life-based gameplay

🧠 Score tracking and leaderboard

🧑‍💼 Admin mode to clear leaderboard (with password)

📱 Responsive and mobile-friendly design

🎵 Sound effects and animations for better UX
